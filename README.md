# VibeBase

AI-native project management workspace for vibe-coding projects.

## MVP
- Project workspace and setup
- Feature prioritization
- Kanban task execution
- Prompt library
- Knowledge base
- Decisions, issues and releases
- Supabase persistence and RLS
- Vercel deployment

## Product workflow
Idea → Discovery → Concept → UX Flow → Design → Specification → AI Coding → Testing → Release → Documentation

## Stack
Next.js · React · TypeScript · Tailwind CSS · Supabase · Vercel

## Development
The repository is under active development. Keep secrets in environment variables; never commit credentials.
